### 1. HB-750M-2 Hysteresis Brake
- **Rated Absorption Torque:** $0\text{ to }5.0\text{ N}\cdot\text{m}$ ($0.05\text{ to }50\text{ kg}\cdot\text{cm}$).
- **Operating Principle:** Magnetic hysteresis. When current energizes the stationary field coil, flux flows through an internal rotor constructed of retentive magnetic alloy. Torque is generated by magnetic drag resisting rotor motion.
- **Key Advantage over Friction & Eddy-Current Brakes:** Torque is strictly proportional to coil current and is **completely independent of rotational speed down to $0\text{ RPM}$**. This permits full static stall torque testing and zero-speed holding.
- **Cooling:** Natural convection / forced air cooling via bench fan.

### 2. FYTH-5-5000-K Dual Torque & Speed Transducer
- **Torque Measurement Range:** $-5.0\text{ to }+5.0\text{ N}\cdot\text{m}$.
- **Torque Sensing Element:** Full-bridge resistive strain gauge on high-tensile shaft with non-contact slip-ring rotary transformer.
- **Torque Zero-Point Baseline:** Center voltage at $2.50\text{ V}$ ($512$ ADC counts on 10-bit Arduino ADC). Clockwise torque increases voltage toward $5.0\text{ V}$ ($1023$ counts); counter-clockwise decreases toward $0.0\text{ V}$ ($0$ counts).
- **Speed Measurement Range:** $0\text{ to }5000\text{ RPM}$.
- **Speed Sensing Element:** Optical slotted rotary disc with optocoupler. Built-in frequency-to-voltage converter outputs an analog $0\text{ to }5.0\text{ V}$ signal proportional to speed ($0.5\text{ RPM per ADC count}$).

### 3. Microchip MCP4725 12-Bit DAC Module
- **Resolution:** 12-bit ($4096$ distinct voltage levels).
- **Interface:** I²C bus at default 7-bit address `0x60` (ADDR pin to GND) or `0x61` (ADDR pin to VCC).
- **Non-Volatile Memory (EEPROM):** Allows storing boot-up voltage and power-down state.
- **Reference Voltage Mode:** Configured by the dyno firmware to $4096\text{ mV}$ reference mode for an exact 1:1 millivolt-to-DAC-code mapping.

### 4. 5251-2 Current-Regulated Power Supply
- Converts the $0\text{ to }5.0\text{ V}$ analog signal from the MCP4725 DAC into a proportional constant-current excitation ($0\text{ to }1.5\text{ A}$) through the hysteresis brake coil.

### 5. Multi-Channel Optoisolated Relay Board
- Three active-HIGH relays driven by Arduino digital pins:
  - **Relay 1 (D2):** Brake Coil Power Supply isolation.
  - **Relay 2 (D3):** FYTH Sensor Excitation Power isolation.
  - **Relay 3 (D4):** Auxiliary bench equipment / cooling fan control.

## 3. Arduino Firmware Architecture (`dyno_controller.ino`)

The firmware resides at `arduino/dyno_controller/dyno_controller.ino` and runs on standard 16 MHz ATmega328P microcontrollers.

### Execution Model
The sketch avoids blocking delays, executing three cooperative tasks in its main loop:
1. **Serial Command Parser (Continuous):** Reads incoming bytes into a line buffer until `\n`.
2. **Hardware PID Control Loop (50 Hz / $20\text{ ms}$ interval):**
   - Samples physical analog pins A0 (torque) and A1 (speed).
   - In closed-loop mode, calculates PID terms:
     $$\text{Error} = \text{TargetTorque}_{\text{counts}} - \text{CurrentTorque}_{\text{counts}}$$
     $$P = K_p \times \text{Error}$$
     $$I = I + (K_i \times \text{Error} \times \Delta t) \quad [\text{clamped to } \pm 4000]$$
     $$D = K_d \times \frac{\text{Error} - \text{PrevError}}{\Delta t}$$
     $$\text{DAC} = \text{clamp}(P + I + D, 0, 4095)$$
   - Writes the new 12-bit value to the MCP4725 DAC.
3. **Telemetry Streaming Loop (20 Hz / $50\text{ ms}$ interval):**
   - Emits structured packet: `<DATA:torque_adc,speed_adc,dac_val>`.

### EEPROM Non-Volatile Memory Map
PID gains are stored at EEPROM address 0:
```cpp
const int EEPROM_ADDR = 0;
struct PIDSettings {
  float Kp; // Proportional gain
  float Ki; // Integral gain
  float Kd; // Derivative gain
} pid;
```
If EEPROM memory is blank or invalid (`isnan()` or out of range $[0, 1000]$), safe factory defaults ($K_p=100.0, K_i=10.0, K_d=1.0$) are restored automatically.

## 4. Custom MCP4725 C++ Library Architecture

Located at `arduino/dyno_controller/MCP4725example/lib/mcp4725/`:

### Key Design Pillars
1. **State-Caching & Staging:** Methods `output()` and `mode()` stage configuration locally in class instance attributes. `update_to_device()` writes the payload over I²C in a single transaction.
2. **EEPROM Lifecycle Protection:** Standard writes use fast command `0x40` (DAC register only). The slower `0x60` (DAC + EEPROM) command is used only when an EEPROM write is explicitly staged via `eeprom()`, protecting the flash memory from write fatigue during 50 Hz PID modulation.
3. **Direct 1:1 Mapping:** Setting `dac.reference_voltage(4096)` enables direct 1:1 mapping between 12-bit integers ($0$ to $4095$) and DAC output codes.
4. **Defensive Error Handling:** Division-by-zero protection in `reference_voltage()`, input validation bounds, and power-down mode persistence across activation/deactivation cycles.

### Host-Level Mock Test Suite
The library includes a complete native C++ unit test suite under `mock_test/` using emulated `Arduino.h` and `Wire.h` headers. It can be compiled and executed on any Linux/macOS/Windows host without physical hardware:
```bash
cd arduino/dyno_controller/MCP4725example/lib/mcp4725/mock_test
g++ -I. -o /tmp/mcp4725_test test_edge_cases.cpp MCP4725_lib_test.cpp
/tmp/mcp4725_test
```

## 5. Load Cell Calibration Mathematical Derivation

The FYTH strain-gauge torque transducer outputs an analog voltage centered around a 2.5V zero-torque reference.

```
0.0V (0 counts)          2.5V (512 counts)              5.0V (1023 counts)
◄───────────────────────────────┼───────────────────────────────►
 -5.0 N·m (Reverse)         0.0 N·m (Zero Load)         +5.0 N·m (Forward)
```

### Derivation Steps:
1. **Raw Count Offset Subtraction:**
   $$\Delta \text{ADC} = \text{ADC}_{\text{raw}} - 512.0$$
   A reading of $512$ corresponds to $0\text{ N}\cdot\text{m}$.
2. **Peak Calibration Measurement:**
   During the calibration wizard, full rated load ($5.0\text{ N}\cdot\text{m}$) is applied to the brake/transducer while energizing the system. The peak raw ADC count ($\text{ADC}_{\text{peak}}$) is recorded.
3. **Slope (Scale Factor) Calculation:**
   $$\text{Span}_{\text{counts}} = \text{ADC}_{\text{peak}} - 512.0$$
   $$\text{torque\_per\_count} = \frac{5.0}{\text{ADC}_{\text{peak}} - 512.0} \quad [\text{N}\cdot\text{m / count}]$$
4. **Final Runtime Conversion Formula:**
   $$\boxed{\tau_{\text{meas}} = (\text{ADC}_{\text{raw}} - 512.0) \times \left( \frac{5.0}{\text{ADC}_{\text{peak}} - 512.0} \right)}$$

### Example Calculation:
If the calibration wizard captures a peak ADC reading of $930$ counts under $5.0\text{ N}\cdot\text{m}$ load:
$$\text{Span} = 930 - 512 = 418\text{ counts}$$
$$\text{torque\_per\_count} = \frac{5.0}{418} \approx 0.0119617\text{ N}\cdot\text{m / count}$$
At runtime, an ADC reading of $721$ counts translates to:
$$\tau_{\text{meas}} = (721 - 512) \times 0.0119617 = 209 \times 0.0119617 \approx 2.50\text{ N}\cdot\text{m}$$
